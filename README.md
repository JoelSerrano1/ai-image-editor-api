# AI Image Editor API

REST API for AI-powered image editing built with Node.js, TypeScript, Express, TypeORM and PostgreSQL.

## Features

- Text to Image
- Sketch to Image
- Magic Eraser
- Image Resizer
- JWT Authentication
- API Key Authentication with rate limits
- PostgreSQL + TypeORM
- Docker Support

## Tech Stack
Node.js, TypeScript, Express 5, TypeORM, PostgreSQL, JWT

## Getting Started

1. Clone: \git clone https://github.com/JoelSerrano1/ai-image-editor-api.git\
2. Install: \
pm install\
3. Copy env: \cp .env.example .env\ (configure)
4. Docker: \docker-compose up -d\
5. Migrations: \
pm run migrations:run\
6. Dev: \
pm run dev\

API at \http://localhost:8080\
